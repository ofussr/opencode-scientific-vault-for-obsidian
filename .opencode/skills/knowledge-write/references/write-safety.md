# Write Safety

Default to surgical edits: add one evidence bullet, extend one relevant section, add a useful alias, add one meaningful relationship, add source-specific corroboration for an existing claim, or add a contradictory result with conditions. A fact can already be known while its supporting evidence is new.

Avoid whole-file rewrites, flattening several sources into one generalized paragraph, reorganizing unrelated sections during ingestion, or deleting older evidence because it is absent from the current source.

Assume existing prose and structure may be deliberate human work. If safe integration is awkward, add new evidence conservatively and leave major restructuring for a separate explicit task. When the user explicitly requests that restructuring, use the dedicated `knowledge-refactor` skill; do not treat the surgical-edit default as a reason to leave an agreed split undone.

For contradictory evidence, keep results, conditions, author interpretations, and unresolved questions distinct. Do not invent an explanation.

Create `[[wikilinks]]` only for meaningful scientific relationships. Do not force inbound/outbound links merely to avoid orphan nodes. An unlinked note is preferable to a meaningless link.
