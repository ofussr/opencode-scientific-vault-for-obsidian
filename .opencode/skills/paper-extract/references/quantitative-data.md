# Quantitative and Structured Data

For every useful number preserve the unit, the minimum conditions needed to interpret it, whether it is measured/calculated/fitted/estimated/nominal/derived, and explicit uncertainty. Do not invent precision.

## Tables
Before using a value: identify the correct row and column, confirm the unit, inspect footnotes, and determine the value type. If PDF extraction flattens the table so the mapping is ambiguous, mark it ambiguous or omit it. Never guess.

## Figures and phase diagrams
Qualitative trends may be extracted when clearly supported by the figure and caption/discussion. Do not invent an exact value from a plotted point or boundary. Do not digitize unless the user explicitly requests digitization. For phase diagrams preserve axes/composition convention, temperature/pressure conditions, named phases/regions, reported boundaries, and whether a boundary was measured or inferred.

## Equations
Do not reconstruct missing or garbled notation from memory. If extraction damages an equation, record that manual verification is required.
